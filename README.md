# MERN To-Do App 🚀

## 📌 Features
- Add Task
- Delete Task
- Time Scheduling

---

## ⚙️ How to Run

### 1. Clone repo
git clone https://github.com/YOUR-USERNAME/mern-todo-app.git

### 2. Install dependencies

#### Server
cd server
npm install

#### Client
cd client
npm install

---

### 3. Run project

#### Start backend
cd server
node server.js

#### Start frontend
cd client
npm start

---

## 🌐 Ports
- Frontend: http://localhost:3000
- Backend: http://localhost:5001

---

## 🧠 Tech Stack
- React
- Node.js
- Express
- MongoDB
